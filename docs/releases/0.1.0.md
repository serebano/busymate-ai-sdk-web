`@busymate/ai-web` 0.1.0: the first official Busymate AI SDK for the web.

- One versioned package for every web integration: the embed (launcher, panel, inline), end-user identity linking with a server-signed token (`identify`/`setUser`, `identityChanged`, `logout`, `switchAccount`, in-chat sign-in handoff), the `busymate-ai-v1` bridge pinned to wire contract v1 (`CONTRACT-v1.md`, `contract.json`), typed events, link status with stable `reason` codes, CSP helpers and the pinned iframe policy.
- ESM + CommonJS + script-tag (IIFE, `window.BusymateAIWeb`) builds with TypeScript types, zero runtime dependencies, SSR-safe import.
- The existing embed script keeps working; see `docs/migration.md`.
- 0.x because the hosted-chat link reason vocabulary (busymate-ai-src#2069) is not settled yet. The wire is stable.

Install:

```sh
npm install https://github.com/serebano/busymate-ai-sdk-web/releases/download/0.1.0/busymate-ai-web-0.1.0.tgz
```

<script src="/vendor/busymate-ai-web-0.1.0.iife.js" integrity="sha256-gVZIM9cok/yfARNIta4h2VBpHGCT+a+wLd9zrkrbRXc=" crossorigin="anonymous"></script>
